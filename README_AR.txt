QUREO Solver Website — نسخة واجهة تجريبية
==========================================

الملفات:
- index.html
- style.css
- app.js

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح لمعاينة الموقع محلياً.

طريقة الاستضافة:
- ارفع مجلد المشروع كما هو إلى خدمة استضافة مواقع ثابتة (Static Hosting).
- اجعل index.html في المجلد الرئيسي للموقع.
- لا تحتاج إلى قاعدة بيانات أو Android Studio لهذه النسخة.

مهم جداً:
هذه النسخة واجهة أمامية تجريبية فقط. أزرار التشغيل والقراءة والمحرر والمعاينة تعمل محلياً داخل الصفحة.
هي لا تقرأ موقع QUREO الحقيقي، ولا تتصل به، ولا تولّد حلولاً بالذكاء الاصطناعي.
لإضافة ذلك لاحقاً نحتاج إضافة متصفح/Userscript لقراءة صفحة QUREO، وخادماً آمناً لتوصيل نموذج الذكاء الاصطناعي، وربطاً مخصصاً بمحرر المنصة. لا تضع مفاتيح API داخل ملفات الواجهة العامة.
